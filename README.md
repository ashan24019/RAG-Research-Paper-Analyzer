# Research Paper RAG Analyzer

Full-stack AI application for analyzing research papers using RAG architecture.

## 🏗️ Architecture
- **Frontend**: React + Vite (TypeScript)
- **Backend**: FastAPI (Python)
- **AI**: OpenAI GPT-4 + text-embedding-3-small
- **Vector DB**: ChromaDB
